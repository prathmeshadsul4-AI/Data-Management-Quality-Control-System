# 📊 Data Management & Quality Control System

A Python-based Data Management and Data Quality Control application designed to manage, clean, validate, store, search, and analyze business data.

## 🚀 Features

- 📥 CSV and Excel data ingestion
- 🧹 Data cleaning and standardization
- ✅ Email and phone validation
- 🔍 Duplicate detection
- 📊 Data quality scoring
- 🗄️ SQLite database storage
- 🔎 Search and filtering
- 🗑️ Record management
- 📈 Dashboard and analytics
- 📋 Department, city and status reports
- 📤 Excel and CSV report export
- 🛡️ Basic data governance rules

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- SQLite
- OpenPyXL
- CSV / Excel
